# سياسة الخصوصية - EchoVerse

## مقدمة

نحن نحترم خصوصيتك ونسعى لحماية معلوماتك الشخصية. هذه السياسة تشرح كيفية جمع البيانات، استخدامها، وتخزينها.

## المعلومات التي نجمعها

- بيانات الحساب مثل البريد الإلكتروني واسم المستخدم.
- بيانات المصادقة عند تسجيل الدخول عبر Google.
- بيانات الاستخدام مثل نشاط المستخدم داخل التطبيق.

## كيفية الاستخدام

نستخدم البيانات لتشغيل التطبيق وتحسين تجربتك، بما في ذلك:

- إدارة تسجيل الدخول والمصادقة.
- تحسين الخدمات والميزات.
- التواصل مع المستخدم عند الحاجة.

## مشاركة البيانات

لا نشارك بياناتك الشخصية مع أطراف خارجية إلا عندما يكون ذلك ضروريًا لتقديم الخدمة أو إذا طلبنا ذلك قانونيًا.

## أمان البيانات

نستخدم إجراءات أمان معقولة لحماية بياناتك من الوصول غير المصرح به.

## الاتصال

إذا كان لديك أي سؤال بخصوص الخصوصية، يمكنك التواصل معنا عبر مستودع المشروع أو القنوات الرسمية للمشروع.
